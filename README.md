# Emberjump 1.0 TEST
Native Java/Canvas Android8+ jump-removal puzzle. Select an ember, then tap an empty tile two spaces away orthogonally, jumping over one ember and removing it. Leave exactly one ember on the marked ring. Twelve rooms, unlimited undo/reset, saved palette/tile numbers, GG007 menu/studio/privacy. Each successful jump reduces the count by one.

Actual Java independent DFS verifies12rooms,6-10jumps. Solution/undo/replay/count/illegal-jump tests pass. Adapter input verifies selection, landing, win, undo/replay,next,menus/settings/privacy/persistence. Pixels inspected. Not phone screenshots. Phone runtime/performance/browser handoff QA incomplete. Not final or Play published.

Functional registry803 scan: only Mastermind feedback pegs, not jump-removal. State is occupancy bitmask, source+landing interaction removes midpoint, unlike earlier route/cargo/orientation games. Known peg-solitaire genre, not global invention.
